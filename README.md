## 住宅IP价格为什么能差出几十倍？

因为“住宅IP”这三个字底下装着三种完全不同的东西，成本差一个数量级。按ASN（自治系统号）看，市面上的IP大致分三档，这个分级直接决定了报价：

| 档位 | 典型ASN | 实际是什么 | 风控表现 |
| --- | --- | --- | --- |
| 高质量住宅IP | AS7922（Comcast）、AS7018（AT&T）、AS6079（RCN） | 真实家庭宽带号段 | 行为接近普通用户，很少被标记为代理 |
| 伪住宅IP | AS2914（NTT）、AS3257（GTT）、AS3356（Lumen） | 机房骨干网，被包装成“住宅” | WHOIS显示backbone/transit，部分平台直接判为proxy/hosting |
| 共享机场IP | AS16276（OVH）、AS9009（M247）、AS24940（Hetzner） | 大量用户共用的数据中心IP | 黑名单率高，容易触发验证码、封号 |

1.3美元/IP这种报价，基本只对应后两类——机房号段大批量进货、多人分摊，单价自然低。真住宅ASN的独享静态IP，号段来自Comcast、AT&T这类家庭宽带运营商，成本高得多。

所以比价之前先做一件事：让商家给出IP的ASN和ISP类型。真住宅IP的WHOIS指向家庭宽带（Cable/DSL/Fiber），流量行为是浏览、视频、社交；伪住宅的WHOIS会暴露backbone、transit字样，行为特征是高并发、稳定长连接。这个信息销售页通常不会主动写，但一句“ASN是多少”就能问出来。
